Testing Guide

  1. Click Load GVM Engine to inject the modifier panel
  2. In the Scan tab, search for a known value (e.g. 100 for HP)
  3. Change the value in-game, then use Next Scan to narrow results
  4. Once found, Set a new value or Freeze it
  5. Try the Speed tab to speed up or slow down the game
  6. Values accessible: TestGame.player.*, TestGame.inventory.*, TestGame.world.*
